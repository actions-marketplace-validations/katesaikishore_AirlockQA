Core Architecture

Core Architectural Pillars

Built for zero-secret exposure, sub-second test execution, and verifiable audit compliance.

01
Host Network Boundary

Phantom Credentials & Deterministic Firewall

The Linux VM never receives real API keys or tokens. Dummy phantom tokens are swapped in-flight at the outbound TAP device by our Go proxy. Any hallucinated destructive mutation like POST /v1/refunds is dropped with 100% mathematical certainty.

// VM Environment: STRIPE_KEY=ph_sec_live_999
// Host TAP Wire: swaps to sk_live_real on api.stripe.com
// Interception: DROPPED (POST /v1/refunds blocked)
02
AI-to-Deterministic Compiler

The "Compile-Once, Run-Free" Flywheel

Running vision models on every test pass costs dollars per run and takes 30 minutes. Run #1 explores with AI; our compiler locks the messy DOM into strict, zero-token Playwright code that runs in 800ms for $0.00. The AI only wakes up when a selector breaks on a future PR.

$ npx airlock explore https://app.acme.com
$ npx airlock compile checkout.trace.json
✔ Emitted zero-token spec: checkout.locked.spec.ts (800ms run)

Developer Quickstart

Get Started in 30 Seconds

Run zero-cost, deterministic tests on your laptop forever with npx airlock:

# 1. Initialize AirlockQA config and phantom credentials
$ npx airlock init

# 2. Explore target application and record high-fidelity DOM trace
$ npx airlock explore http://localhost:3000

# 3. Compile AI exploration into zero-token deterministic Playwright test
$ npx airlock compile checkout.trace.json

# 4. Execute test with zero secrets in memory & deterministic egress guard
$ npx airlock test --local

Dispatch directly to our bare-metal Linux MicroVM fleet from GitHub Actions or CI/CD:

# In your GitHub Actions or CI/CD pipeline:

export AIRLOCK_CLOUD_URL="https://qbrin.cloud/api"

# Dispatches to Bare-Metal Linux MicroVM with 120ms cold boot & TAP isolation

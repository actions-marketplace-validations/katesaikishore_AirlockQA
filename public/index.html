Architecture

Core Architectural Capabilities

Designed for zero-secret leakage, sub-second test runs, and mathematically verifiable compliance.

01 • Network Boundary Host TAP Edge

Phantom Credentials & Egress Firewall

The Linux VM never receives plaintext API secrets or OAuth tokens. Outbound HTTP requests pass through the host TAP wire interface, where our Go proxy validates the destination domain and injects real secrets in-flight. Unauthorized mutations like POST /v1/refunds are dropped.

// Guest VM Sees: STRIPE_KEY=ph_sec_test_dummy
// Host Wire Swap: swaps to sk_live_*** on api.stripe.com
// Interception: DROPPED (POST /v1/refunds blocked)
02 • Deterministic Engine Zero-Overhead Runner

Deterministic Compiler & Self-Healing

Exploratory browser runs are compiled into deterministic Playwright TypeScript tests that execute in under 800ms. If a frontend UI component refactors, the built-in similarity engine resolves broken selectors using token-overlap and DOM tree analysis without failing test passes.

$ npx airlock explore http://localhost:3000
$ npx airlock compile checkout.trace.json
✓ Emitted deterministic test: checkout.spec.ts (800ms run)
03 • State Checkpointing Copy-on-Write RAM

Sub-Second State Forking & Replay

Rather than re-executing 20 preparatory steps for every edge case, capture warm memory snapshots at key steps (e.g., Authenticated Session, Populated Cart) in 7ms. Clone 5 parallel variations in 135ms, and inspect failures at the exact point of execution.

04 • Audit & Attestation Ed25519 Signer

Cryptographic Proof & Compliance Ledger

Every executed DOM mutation, network request, and blocked policy violation is hashed into an immutable Merkle tree and signed with Ed25519 keys. Security auditors receive mathematical proof that tests ran without leaking customer data.

Quickstart

CLI Installation & Execution

Run zero-cost, deterministic tests on your laptop with npx airlock:

# 1. Initialize AirlockQA configuration and sample policy
$ npx airlock init

# 2. Record exploratory browser session
$ npx airlock explore http://localhost:3000

# 3. Compile recorded trace into deterministic Playwright spec
$ npx airlock compile checkout.trace.json

# 4. Execute test with client-side credential proxy
$ npx airlock test --local

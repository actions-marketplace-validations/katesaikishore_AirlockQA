    GOVERNANCE / API & CI/CD

    Connect your pipeline

    Submit test runs from CI with the Airlock CLI.

    API available
    1Install CLI
    2Set API key
    3Run in CI
    01

    Install and submit a run

    Airlock Cloud accepts run submissions at POST /v1/runs.

    TERMINAL
    npm install --save-dev airlockqa
npx airlock test --cloud
    TERMINAL
    bun add --dev airlockqa
bunx airlock test --cloud
    ✳ The CLI submits a run request and displays the response provided by the configured cloud deployment.
    02

    Add the API key to CI secrets

    Store AIRLOCK_API_KEY in your CI provider. Never commit the key.

    ⌑
    Secret nameAIRLOCK_API_KEY
    Set in CI provider
    Create and manage keys in the account portal. Keys are not shown in this preview.
    03

    GitHub Actions workflow

    Run on pushes and pull requests using an encrypted secret.

    ● ● ●   .GITHUB/WORKFLOWS/AIRLOCK.YML
    name: Airlock QA
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: bun install
      - run: bunx airlock test --cloud
        env:
          AIRLOCK_API_KEY: ${{ secrets.AIRLOCK_API_KEY }}
    ↗
